# reglas/clientes/

Carpeta reservada para reglas **propias de cada cliente** (por ejemplo, un concepto de retención
distinto para un proveedor habitual). En esta versión los perfiles de cliente se guardan en
`~/.dian_hojas/retefuente.sqlite` y las reglas generales del año en `reglas/[año].yaml`.

Si más adelante se necesitan excepciones por cliente, este es el lugar: un YAML por NIT, sin datos
reales en el repositorio.
